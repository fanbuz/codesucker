## 客户端与 Release 验收标准

最终候选需通过三平台安装包构建和 Windows 启动冒烟；macOS 客户端使用独立临时工程及用户目录验证界面加载、preload、后台扫描、错误配置恢复、原子保存和未来 schema 拒绝覆盖。运行链接和实际结果回填 #78。

正式标签必须指向已合并候选，发布工作流重新验证并生成 macOS x64、macOS arm64、Windows x64 安装包及 SHA256SUMS。Release 发布后核对三个附件的产品版本、名称及下载文件校验和。语言注册表、扫描性能重构、全量 IPC、Hooks lint 和 sandbox 启用不在本补丁范围。

## 兼容与持久性边界

有效的 `false` 清洗开关、工程外导出目录、文件排除和手动顺序保持原有含义。无效字段丢弃或逐项补默认值；文件顺序和排除列表只保留当前扫描中的相对路径并去重。未来整数 schema、符号链接和非普通配置文件拒绝覆盖。

替换前失败保留原配置；POSIX 替换后同步父目录，若失败则明确报告持久性未确认。Windows 不额外承诺断电持久性。SIGKILL 和断电无法执行清理回调，可能遗留独占临时文件；应用不扫描或删除未知残留。POSIX 信号测试仅在支持的平台运行。macOS 安装包仍未签名和公证，处理指引保留在 Release 与 README。
